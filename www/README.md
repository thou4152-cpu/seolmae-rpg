# Dungeon RPG Prototype

가벼운 중세 판타지 턴제 RPG 1층 프로토타입입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages
세 파일(index.html, style.css, game.js)을 저장소 루트에 업로드한 뒤
Settings → Pages에서 배포하면 됩니다.

## 현재 구현
- 전사/도적/궁수/마법사
- Lv/EXP/HP/MP/기본 능력치
- 1~3마리 턴제 전투
- 일반 고블린 4종 / 엘리트 / 고블린 족장
- 도망, 방어, 포션
- 직업별 기본 스킬 2종 및 전투 중 스킬 선택/대상 선택
- 골드/경험치/장비 드랍
- F~C 장비 및 품질
- 장비 강화
- 마을, 상점, 대장장이
- 휴식 시 진행도 2 감소
- 귀환 성공/실패
- 스테이지 후 5% 희귀상인
- localStorage 자동 저장

스킬 트리, 특성, 궁극기, 거리 시스템의 완성형 등은 이후 단계에서 확장합니다.


## v9 이미지 적용
현재 게임에 존재하는 무기, 투구, 갑옷, 장갑, 신발, 목걸이, 반지, HP/MP 포션의 이미지가 상점/인벤토리/장비창/드랍 보상에 연결되어 있습니다.
